# Bird-Dex — Bold Pixel Expansion v1

19 new PNG assets, supplied flat for review and handover to Claude.

| Group | Files |
|---|---|
| Birds | Blue tit, great tit, blackbird, mallard, mute swan, wren, great spotted woodpecker, kestrel, buzzard |
| Ground textures | Grass, water, woodland floor |
| Markers | Normal site, target site, selected site |
| Scenery | Broadleaf tree, conifer, bush, reeds |

The nine new birds join the three previously supplied anchors (robin, kingfisher and grey heron) to make a 12-bird starting set. Those anchors are not duplicated here.

## What to open

- Open the PNGs to review the art. Each file contains one bird, marker, scenery object or texture.
- Give `CLAUDE_HANDOVER.md` to Claude with this ZIP.
- `asset_manifest.json` records exact filenames, roles, dimensions, transparency, checksums and remaining work.

## Status

All 19 files are **1254 × 1254 pixel design masters**. The 16 birds/markers/scenery images have real transparent backgrounds. The three ground textures are opaque RGB PNGs.

The Bold Pixel direction is selected. This new batch is for review; it has not been approved as final production artwork. These files have a pixel-art appearance but are not yet exact small-grid sprites. They contain subtle raster texture and soft alpha; some have very faint alpha-1 stray edge pixels. The main visible silhouettes fit inside the canvases without clipping.

The textures have repeatable-design intent, but their opposite border pixels differ. They require seam repair and a repeated-grid visual check before being treated as seamless runtime tiles.

## Suggested next review

Check the nine birds beside the existing anchors, then check markers at small display sizes. Flag only specific assets that need changes. Keep the good ones and refine the exceptions before bulk native-grid conversion.

No repository access, credentials, API keys or deployment is needed to review this pack.
