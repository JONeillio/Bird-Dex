# BirdQuest foundation pack

Prepared 7 November 2026 for a later implementation handoff.

Start with [BirdQuest_Foundation_Plan.md](BirdQuest_Foundation_Plan.md). Give the next builder [Next_Model_Handoff.md](Next_Model_Handoff.md) together with the full pack and the visual concept from the conversation.

Contents:

- `BirdQuest_Foundation_Plan.md`: product, game map, collection rules, sources, feasibility, architecture, stages and acceptance criteria.
- `Next_Model_Handoff.md`: concise instructions and exact status for the next model.
- `design-tokens.json`: proposed visual/interaction tokens.
- `contracts/domain.ts`: app-owned TypeScript type proposals for implementation planning.

This is a planning package. There is no runnable application, authenticated API test, real personal-history import, remote GitHub repo or deployment. The contract types are not verified provider schemas. Research limitations and unverified assumptions are listed in the plan.

Keep personal exports, precise origin settings and real API keys out of a future repository. Retain source and per-asset credits when implementing.
